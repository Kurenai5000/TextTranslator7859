1.Run by opening the "main.html" file to open the webUI in your browser.
2.Input your deepseek API key in the "Input your API key" section.
3.Click "Choose File" to input a .txt file to translate.
4.Click the "Start Translation" button.
5.Once completed, click the "Download Translation" button.

I created this with great help from deepseek which did a lot of the programming in order to translate an old Chinese book.

Currently only tested with Chinese to English.

Make sure to use a deepseek API key or edit it to work with other LLM API's.
Use a txt file to translate.
